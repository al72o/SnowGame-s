Целевая версия

Как должна замкнуться причинно-следственная модель

Сейчас

Прогноз и ёмкость частично декоративны.
Аренда в основном влияет только на расходы.
Покупательская потребность qty не полностью исполняется.
Конкуренты — фон с упрощённой экономикой.

Целевая цепочка

Прогноз → скрытый фактический спрос.
ТЦ + места → доступный покупательский поток.
qty + бюджет + maxPrice → реальные повторные покупки.
Продажа → склад продавца + бюджет покупателя + P&L → decisionLog → дебрифинг.
