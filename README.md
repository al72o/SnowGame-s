# Снежинка AI

Личный прототип цифровой версии деловой игры РРС «Снежинка» (курс развития
топ-менеджмента ДНС, версия 3 от федерального офиса). Экономика игры —
реальные цены, аренда, потребности покупателей по всем 8 кварталам
2026–2027 — перенесена как есть. Живых ведущих, покупателей, поставщика и
двух команд-конкурентов заменяет подключаемый AI-агент.

Это не официальный цифровой продукт ДНС — рабочий прототип для проверки
идеи, собранный на основе исходных материалов курса.

## Быстрый старт (без единого ключа)

```
npm install
npm start
```

Откройте `http://localhost:3000`. По умолчанию используется провайдер
`stub` — без обращения к какой-либо модели, на задокументированных
детерминированных правилах игры (тот же офлайн-режим, что был в самой
первой версии прототипа). Это осознанный выбор по умолчанию: игра
полностью проходима и без единого API-ключа.

## Подключить живой AI

1. Скопируйте `.env.example` в `.env`.
2. Пропишите:
   ```
   AGENT_PROVIDER=openai
   OPENAI_API_KEY=sk-...
   OPENAI_MODEL=gpt-4o-mini
   ```
3. Перезапустите `npm start`.

`openai.js` работает не только с OpenAI: любой OpenAI-совместимый эндпоинт
подходит — поменяйте `OPENAI_BASE_URL` (self-hosted модель, OpenRouter и
т.п.). Именно так «на другой машине» подключается другой агент — код
трогать не нужно, только `.env`.

## GigaChat / YandexGPT

Ещё не реализованы — в `server/providers/gigachat.js` и
`server/providers/yandexgpt.js` подробно расписано, что именно нужно
доделать (аутентификация, формат запроса, отличия от OpenAI-совместимого
API). Выбор между ними и OpenAI-совместимым провайдером — открытый вопрос
(нужно сравнивать, в т.ч. в контексте требований контура DNS/Simulacia
Claude), поэтому оба оставлены как явные заготовки, а не молчаливые заглушки.

## Где именно нужен агент и как он должен себя вести

Подробный контракт (входы/выходы, точные промпты, поведенческие требования
для каждой из 5 точек, где физическая игра требовала живого человека) — в
[`AGENT.md`](./AGENT.md). Прочитайте его перед тем, как менять промпты или
подключать нового провайдера.

## Известные упрощения прототипа

- Роли внутри команды не разделены — размер команды влияет только на
  производственную мощность (8 изделий за квартал на человека).
- Реальная физическая резка/сборка изделий не моделируется — стандарт
  качества считается выполненным автоматически.
- Экономика конкурентов упрощена (прибыль оценивается по марже, не по
  полному P&L).
- Одновременная игра нескольких живых людей одной командой (совместное
  редактирование состояния) не реализована — состояние хранится в
  `localStorage` одного браузера. Для честной командной игры нескольким
  людям вокруг одного экрана — работает; для игры с разных устройств
  одновременно — нет.
- Сплит продаж на 4 кв. 2027 в исходных материалах федерального офиса
  повреждён (те же нечитаемые символы, что и в присланной презентации) —
  в `data/game_data.json` подставлено значение по аналогии с 4 кв. 2026,
  и это явно помечено флагом `splitPatched` и предупреждением в интерфейсе.

## Дебрифинг — не факультативная фича

Ключевой результат игры — не то, какая команда заработала больше, а
дебрифинг: разбор действий, объяснений и предпосылок каждого участника,
который формирует понимание того, как проявился его уровень руководителя.
В прототипе это отдельный 4-шаговый режим (реакция → факты → анализ →
выводы и планы), построенный на логе решений, который игра ведёт
автоматически по ходу партии. Подробности — в `AGENT.md`, задачи
`debrief_facts` и `debrief_analysis`.


## Docker + домен

Production-подготовка находится в ветке `feat/docker-domain-ai-agent`.
Она включает Docker, интеграцию с существующим Nginx, обязательную авторизацию, healthcheck и rate limit
для AI endpoint и готовую конфигурацию для
`https://ru.cheapvibecode.ru/v1` + `gpt-6-luna`.

Автоматическая установка после checkout:

```bash
sudo bash install.sh
```

После установки быстрый реальный тест модели:

```bash
cd /opt/snowgame
sudo bash scripts/live-ai-smoke.sh
```

Полный тест всех пяти AI-ролей:

```bash
sudo bash scripts/live-ai-smoke.sh --full
```

Полная инструкция: [DEPLOY.md](DEPLOY.md).
